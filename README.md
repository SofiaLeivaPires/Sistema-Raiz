# Sistema de Cadastro de Produto

## Descrição
Esse projeto é um exemplo para treinamento de jovens aprendizes. Ele consiste em um sistema simples de cadastro de produtos, desenvolvido para demontrar boas práticas de desenvolvimento de software.

## Obejtivo 
Criar uma aplicação básica que permita:
- Adicionar produto.
- Listar produtos cadastrados.
- Excluir produtos.

## Tecnologias utilizadas
- **Linguagem:** C# (ASP.NET)
- **Banco de Dados:** SQLite
- **Controle de Versão:** Git e Github
